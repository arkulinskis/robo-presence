Connection servers

Browsers and robots use these to find a path to each other. STUN is enough on most networks. Strict networks (some offices, some mobile carriers) need a TURN relay. The app adds a Cloudflare relay by itself when the app secrets cf_turn_key_id and cf_turn_api_token are set (Cloudflare dashboard > Realtime > TURN); you can also list your own (urls starting with turn: or turns:, with a username and credential).

Faster check-ins connect pilots sooner but make more server calls (one per robot per check-in).
